# Repository configuration

Every setting of this repository lives in a file, and each file explains in its
comments what each element is for and why it was chosen. This page is only the map:
it groups those files by topic and lists the steps to replicate the repository.
Values (versions, check names, SHAs) are never copied here, so the files stay the
single source of truth.

## Replicate the repository

Requirements: `gh` (logged in with admin rights), `terraform` (see
`required_version` in `infra/github/versions.tf`), `uv`, and the `gh-actions-lock`
extension (`gh extension install github/gh-actions-lock`).

1. **Adapt the names.** Change the owner in `infra/github/versions.tf` and the
   repository name in `infra/github/repository.tf` and `infra/github/api-only.sh`.
   Delete `infra/github/imports.tf`: it adopts the existing repository.
2. **Create the empty repository** without the ruleset, so the first push to `main`
   is allowed:

   ```bash
   cd infra/github
   terraform init
   terraform apply -target=github_repository.pocs
   ```

3. **Push the code** to the new repository's `main`.
4. **Apply the rest of the settings** (ruleset, Actions, security), then the ones the
   provider does not support yet:

   ```bash
   terraform apply
   ./api-only.sh apply
   ```

5. **Manual step, no API:** Settings → Actions → Policies → new policy
   `require-lockfile`, status **Active**, protection **Require lockfile**. It blocks any
   workflow missing from `actions.lock`.
6. **Locally:** `uvx --with pre-commit-uv pre-commit install`, and in each POC folder
   `make update-tooling` and `uv sync`.

## Check for drift

Settings changed in the GitHub UI are not versioned. Check them against the files:

```bash
cd infra/github
terraform plan          # "No changes" means the settings match
./api-only.sh check     # exit 1 on drift
```

`terraform apply` and `./api-only.sh apply` restore the declared state. OpenSSF
Scorecard (weekly) also reports weakened settings as alerts in the Security tab.

## Keeping this page useful

Change a setting in its file, with the reason in a comment, in the same pull request.
Update this page only when a file is added, moved or removed.
